# مختبر بسيط لتعلّم الفوترة مع Lago

هذا المشروع يشرح دورة واحدة من البداية إلى النهاية:

```text
المتصفح → FastAPI → نموذج مجاني عبر OpenRouter → قياس التوكنز → Lago (اختياري)
```

يستدعي الباك إند واجهات HTTP مباشرة. لا توجد SDK تخفي الطلبات في هذا المثال.

## 1. تشغيل التطبيق

افتح الطرفية داخل مجلد المستودع:

```bash
cd /home/Belus/Downloads/invo/test-lago
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp -n .env.example .env
```

افتح ملف `.env` وضع مفتاح OpenRouter جديدًا بعد `OPENROUTER_API_KEY=`. لا تضع المفتاح في ملف Python أو في Git. ثم شغّل الخادم:

```bash
.venv/bin/uvicorn main:app --reload
```

افتح <http://127.0.0.1:8000>. أوقف الخادم من الطرفية باستخدام `Ctrl+C`.

## 2. اختيار نموذج مجاني

تطلب الصفحة قائمة النماذج من `GET /api/models`. يقرأ الباك إند فهرس OpenRouter ويعرض نماذج المحادثة النصية فقط عندما يكون سعر الإدخال وسعر الإخراج في الفهرس صفرًا. اختر نموذجًا محددًا من القائمة، أو اختر التوجيه التلقائي.

قبل كل طلب محادثة، يتحقق الباك إند مرة أخرى من أن النموذج المحدد لا يزال مجانيًا. قائمة النماذج وحصصها قد تتغير، لذلك لا يعني ظهور النموذج أن الخدمة تضمن توفره دائمًا.

## 3. كيف يمر طلب المحادثة؟

1. الصفحة ترسل نص السؤال ومعرّف النموذج إلى `POST /api/chat`.
2. `main.py` يتحقق أن مفتاح OpenRouter موجود وأن النموذج مجاني.
3. `openrouter_service.py` يرسل HTTP POST إلى OpenRouter ويقرأ الرد وعدد التوكنز.
4. `main.py` يحسب سعرًا تجريبيًا للعميل. هذا السعر من إعدادنا في `.env`؛ تكلفة النموذج المجاني على OpenRouter تظل صفرًا بحسب الفهرس.
5. إذا كانت إعدادات Lago موجودة، يرسل `lago_service.py` حدث استخدام واحدًا إلى Lago.

اقرأ الملفات بهذا الترتيب: `main.py` ثم `openrouter_service.py` ثم `lago_service.py` ثم `settings.py`.

## 4. تهيئة Lago محليًا

واجهة Lago المحلية تعمل على <http://localhost:8080> وواجهة API على <http://127.0.0.1:3001/api/v1>. أنشئ مؤسسة وحسابًا محليًا من واجهة Lago أولًا.

إذا أردت إنشاء حاوية Lago جديدة بنفس المنافذ، شغّلها هكذا (لا تُعد تشغيل الأمر إذا كانت حاوية `lago-demo` موجودة بالفعل):

```bash
podman run -d --name lago-demo \
  -p 127.0.0.1:8080:80 \
  -p 127.0.0.1:3001:3000 \
  -e API_URL=http://localhost:3001 \
  -e LAGO_FRONT_URL=http://localhost:8080 \
  -v lago-data:/data \
  docker.io/getlago/lago:latest
```

يجب أن يشير `API_URL` إلى المنفذ الذي يراه المتصفح، وأن يطابق `LAGO_FRONT_URL` عنوان الواجهة. إذا اختلفا، قد تظهر صفحة التسجيل بينما تفشل طلباتها بصمت.

بعد الدخول، أنشئ مقياس استخدام بالكود `ai_tokens` يجمع قيمة الخاصية `value`، ثم أنشئ خطة وعميلًا واشتراكًا. ضع مفتاح API ومعرّف الاشتراك الخارجي في `.env`:

```text
LAGO_API_KEY=مفتاح-من-لوحة-Lago
LAGO_EXTERNAL_SUBSCRIPTION_ID=معرف-اشتراك-العميل
LAGO_EVENT_CODE=ai_tokens
```

أعد تشغيل FastAPI بعد تعديل `.env`. سترى في نتيجة المحادثة هل استقبل Lago الحدث. عند ترك الإعدادات فارغة، لا يرسل التطبيق أي شيء إلى Lago.

## 5. سعر العميل التجريبي

القيمة الافتراضية في `.env` هي `DEMO_PRICE_PER_1000_TOKENS=0.001`. معناها أن التطبيق يعرض واحدًا من ألف دولار لكل ألف توكن كمثال تعليمي. عدّلها إذا أردت. هذا السعر الافتراضي لا يغيّر سعر OpenRouter، ولا يصبح فاتورة من Lago حتى تهيّئ خطة واشتراكًا.

## تذكير

مفاتيح OpenRouter وLago أسرار. ملف `.env` محلي ومستثنى من Git. إذا سبق أن شاركت مفتاحًا في محادثة أو مستودع، ألغِه وأنشئ مفتاحًا بديلًا.
